How to use

  1. 1
    Enter your access key

    Get this from your order status page after payment is approved.

  2. 2
    Add your Telegram number

    Use country code (e.g. 639171234567). We'll send a Telegram OTP code.

  3. 3
    Verify with OTP

    Enter the code Telegram sends you — no password needed.

  4. 4
    Set post link & targets

    Add the exact post URL and destination @groups.

  5. 5
    Start forwarder

    Hit Start — the saved post is forwarded on each cycle.

Phone logged out?

Forwarding runs on our server as Loveriette Forwarder — you can log out on your phone and close this tab. Do not tap Terminate all sessions in Telegram Settings → Devices.

Tip

Your account must be a member of both the source chat and target groups/channels.
