How to use

  1. 1
    Enter your access key

    Get this from your order status page after payment is approved.

  2. 2
    Add your Telegram number

    Use country code (e.g. 639171234567). We'll send a Telegram OTP code.

  3. 3
    Verify with OTP

    Enter the code Telegram sends you — no password needed.

  4. 4
    Set source & targets

    Add the chat to forward from and where messages should go.

  5. 5
    Start forwarder

    Hit Start — messages relay live through your Telegram account.

Tip

Your account must be a member of both the source chat and target groups/channels.
