How to use Email Fetcher

  1. Select your account

    Choose the email/account you want to fetch from the dropdown above.

  2. Trigger the email first

    Before fetching, open the service (Netflix, Canva, etc.) and sign in with your purchased account. If you need a verification code, OTP, or login link, request it on that site first — this sends the email to the inbox.

  3. Fetch the email

    Return here and click Fetch. The latest message for that account will appear below (verification codes, login links, etc.).

  4. Changing password

    Same process: change the password on the service first, then fetch here to read the confirmation or security email.

Tip: If nothing appears, wait a few seconds after requesting the code on the service, then fetch again.
